# Layout & CSS

- Use **Tailwind CSS** via a single external stylesheet (no inline `<style>` blocks).
- Apply Tailwind utility classes directly in HTML markup.
- Use **Flexbox** (`flex`) for page layout and component alignment.
- **Never** use `float` or `display: inline-block` for page structure.
- Extend with CSS custom properties (`--var`) in the Tailwind config or global CSS for consistent spacing, colors, and breakpoints.
