# .agents

This directory houses configuration, rules, and scripts for AI agents working in this repository.

## Structure

```
.agents/
├── README.md       # This file
├── rules/          # Agent rules, conventions, and guidelines
└── scripts/        # Utility scripts for agent workflows
```

## Rules

Place markdown files in `rules/` to define project-specific conventions, coding standards, and behavioral guidelines for AI agents.

## Scripts

Place executable scripts in `scripts/` to automate common agent tasks (e.g., linting, building, testing, or project-specific utilities).
